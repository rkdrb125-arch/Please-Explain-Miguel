# Please Explain, Miguel v0.11 — 병맛 스무고개 개편

v0.10을 기반으로 한 개그 추리 개편판입니다. 기존 저장 키 `please-explain-miguel-v1`과 수사·타임라인·리포트·평가 기능 및 `CHARACTER_LORE.md`를 유지합니다.

- 신규 독창적 사건 3개: 거울에 김이 서린 실종 신고 / 과자 부스러기 알리바이 / 건물 그늘의 그림자 실종
- 사건당 질문 규칙 4종과 논리적으로 확인 가능한 정답
- 미겔·다니엘라의 개그 대화 및 사건별 오답·정답 반응
- 기존 자유 질문은 키워드 매칭 방식이며, 지원하지 않는 질문은 확답하지 않습니다.
- 기존 클리어 기록은 그대로 남으며, 과거 사건의 기록이 새 이야기의 내용과 맞지 않을 수 있습니다. 새 이야기를 처음부터 즐기려면 START를 누르세요.

## 배포
ZIP 압축을 풀고 파일 3개를 저장소 루트에 업로드합니다. `index.html`을 정적 호스팅으로 배포합니다.

## 검증 범위
JS 구문과 ZIP 무결성 검사를 실시했습니다. 실제 브라우저 수동 플레이 테스트는 별도 필요합니다.
